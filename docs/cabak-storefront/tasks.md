# CABAK implementation tasks

Status: Pending approval. Documentation only in this phase.

1. Approve requirements and visual direction; collect merchant inputs.
2. Capture reference homepage, collection and product patterns on desktop/mobile;
   document observed states without copying third-party content.
3. Confirm Shopify access and establish an unpublished preview theme.
4. Apply CABAK tokens and authorized logo assets. Validate R1, R7 and R8.
5. Configure editable homepage and navigation. Validate R2 and R9.
6. Style catalogue/product/cart surfaces with actual merchant content.
   Validate R3-R5 through available/unavailable variants and cart errors.
7. Configure approved provider integrations in merchant accounts.
   Validate R6 with supported success, failure, cancellation and pending flows;
   verify final order/payment state in Shopify.
8. Complete shipping, policies, domain and contact information.
9. Validate responsive layout, keyboard flow, contrast, reduced motion,
   theme checks, preview performance and console/network failures.
10. Verify Graphify coverage and update structural evidence for changed files.
11. Present the tested preview and release checklist for publication.

Release blockers: missing catalogue/media, merchant/payment access, unverified
provider activation, incomplete shipping/policies, or failed critical purchase flow.
